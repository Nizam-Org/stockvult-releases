# StockVult downloads

Windows installers and update files for StockVult. A valid licence key is required to edit records.

Download the `stockvult-…-win-x64-setup.exe` installer from **Releases**. Install it, open StockVult, and enter the licence key supplied by the app owner.

Updates are offered at startup and in **Settings → App updates**. Download an update, save your edits, and choose **Restart and install**.

This repository contains release files only. Application source code is maintained privately. Availability of these downloads does not grant a licence to use, copy, modify or redistribute the application.
